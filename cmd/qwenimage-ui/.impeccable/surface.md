# QwenImage workspace

Mode: Operate. Scope: the single local browser screen in web/.

## Direction contract

THESIS: A small image workbench where the prompt, result, and actual execution
state stay together. A queue groups images to share model loads by stage.

OWN-WORLD: A light graphite workspace, white controls, restrained forest green
actions, system typography, thin dividers, consistent 6px control corners.

STORY: Enter a prompt, optionally add ordered references, choose settings and an
output folder, enqueue seed variations, start/pause the queue, inspect, and
download. Enter the output path directly or browse local folders. Select a job
for progress, cancellation, its saved destination, and settings reuse. Errors
preserve the prompt.

FIRST VIEWPORT: A compact masthead, a 340px form column, and a generous preview
with an honest empty state. Add to queue sits after the core controls. Queue
controls and selectable rows follow the preview. Advanced settings and logs
expand inline. On narrow screens the form precedes the preview and queue, with
full-width actions and no horizontal overflow.

FORM: Direct code implementation of the user's narrowly scoped local browser
utility. System controls and clear status take priority over ornamental assets.
The signature interaction is the output replacing the empty canvas while its
run details remain available. Only functional state transitions animate.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
